## 0. 研究の進め方（このプロジェクトの規律）★最初に読むこと

本プロジェクトは**仮説駆動**で進める。思いつきで施策を実装しない。

```
研究主題（AIで素晴らしいキャラを生み出し続ける）
  ↓
① 主題を支える【仮説】を1つ立てる
  ↓
② その仮説を検証する【実験計画】を立てる
   ・測定する量、判定基準、必要サンプル数を【事前に】決める
   ・是のとき／非のとき、それぞれ次に何を問うかも【事前に】決めておく
  ↓
③ 実験を実施し【是 / 非 / 判定不能】を判定する
  ↓
④ 結果を踏まえて【次の仮説】を立てる
   ・是 → その成立を前提に、一段深い問いへ
   ・非 → 否定された内容を踏まえ、別の説明を問う
   ・判定不能 → 検出力・交絡を直して問い直す（新しい問いに逃げない）
  ↓
①へ戻る（主題に到達するまで反復）
```

### 守る規則

1. **事前登録**: 判定基準・必要nは実験の前に書く。結果を見てから基準を決めない。
2. **分岐の事前設計**: 是／非の両方について、次の仮説を先に書く。後付けの正当化を防ぐ。
3. **判定不能を是と呼ばない**: 検出力不足は「効果なし」でも「効果あり」でもない。
4. **未検証の代理指標を最適化しない**: 代理を使うなら、先にその妥当性を検証する。
5. **否定結果を残す**: 反証された仮説は消さず、判定と根拠を記録する（§1の表）。
6. **交絡を先に潰す**: ランダム化した2群をそのまま比べない。1軸だけ振る。
7. **記録は本ファイルに集約する**: 新しい判定・決定が出たら、まず §1-b と §10 に追記する。
   新しいMDファイルを増やさない。詳細な分析は付録ファイルに置いてよいが、**結論と判定は必ず本ファイルへ書き戻す**。

### 提案・議論のトーン

施策の提案は必ず「**どの仮説を検証するためか**」から始める。
「次は◯◯を実装しましょう」ではなく「**主仮説A/B/C のどれを進めるために、下位仮説◯を検証する。そのための実験が◯◯**」の形にする。

## 1. 主仮説（研究主題を満たすための3本）★これが計画

研究主題「**AIで素晴らしいキャラを生み出し続ける**」が成立するには、次の3つが**すべて**必要。
逆に言えば、この3本を立証できれば主題に到達する。**A → B → C の順に依存**しており、順番は入れ替えられない。

| | 主仮説 | 内容 | 現状 |
|---|---|---|---|
| **A** | **測れる** | 「素晴らしさ」は、人手を介さず**測定可能な量**に分解できる | 🔶 **半分成立**（識別性は測れる／記憶可能性は未達）← **いまここが律速** |
| **B** | **原因が特定できる** | AIが人手設計に届かない原因は、描画能力ではなく**目的関数と参照の欠如**である | 🔶 **状況証拠のみ**（因果は未検証） |
| **C** | **介入で埋まる** | その原因に対応する機構を入れると、**Aで測った差が実際に縮む** | ⚠️ **未達**（中核の識別性では示せていない） |

> **依存関係**: Aが無ければCの効果は判定できない。Bが無ければCで何を入れるべきか決まらない。
> **★これまでの失敗の説明**: 私はAが未完成のままCに手を出していた（未検証の指標で棄却サンプリングを回そうとした）。
> 3本構造にすると、この誤りが構造的に見える。**Aを閉じるまでCに進まない。**

## 4. なぜ「投稿不可」なのか（S4が崩れた経緯）

詳細は `analysis/embedding-validation-memo.md`。要約:

1. 当初 E-A で「介入後は平均輪郭 2.21 vs 介入前 1.75（**差+0.46**）、σも 0.50 vs 0.39」→ 識別性が上がったと解釈した。
2. 独立指標（DINOv2埋め込みのペアワイズ距離）で検証 → **差が出ない。むしろ符号が逆**（0.331 vs 0.351、p=0.29）。
3. 原因を調査 → **2条件のレア度構成が揃っていなかった**（post は epic/legend が10/12体、pre は5/12体）。レア度自体が輪郭を強く決めている（common 1.34 → legend 2.36）。
4. **同一レア度どうしで比較し直すと**、形状指標の差は **+0.46 → +0.14**（約7割が交絡）、埋め込みは **−0.006（p=0.80）**。
5. → **2指標の不一致ではなく、実験計画の不備**。両指標とも統制後は「ほぼゼロ」に収束する。

**効果がゼロと確定したわけでもない**（epic +0.20 / legend +0.23 と符号は揃う）。現データでは**判定不能**が正確。

## 5. 現在の仮説と実験計画（事前登録）

### 検証中: 【A2】記憶可能性は測れるか — 仮説「記憶可能性は孤立効果で説明できる」

**なぜこの仮説か**: 主仮説A（測れる）の律速がA2。H9 が非（現行の形状指標では記憶可能性を説明できない）だったため、別の説明が要る。
理論的根拠は記憶研究の**孤立効果 / von Restorff effect**（集団の中で異質なものほど記憶に残る）。
これは杉森建の原則7（あえて崩して記憶に残す）とも整合し、**記憶可能性は個体の属性ではなく集団に対する相対的位置で決まる**という予測を生む。

**測定する量**: 項目ごとのヒット率（再認課題で「見た」と答えられた割合）
**予測変数**: 重心距離 / 近傍孤立度 / 最近傍距離 / マハラノビス（すべて参照ロスター1025体を母集団として計算）

**実験計画**:
- 固定項目セット（study 45・lure 45）を全参加者に提示 → **分析単位は参加者ではなく項目**
- source（生成/参照）を study と lure で厳密に均衡（各 生成25＋参照20）
- 候補指標の値が広く散るよう層化抽出（予測変数の分散を最大化＝検出力を最大化）
- 提示 1.2 秒 → 20 秒の干渉課題 → 再認 90 試行
- 参加者 5 名 → **項目あたり5観測 × 45項目**

**判定基準（事前に決定）**:
- **是**: いずれかの候補指標が、項目ヒット率と ρ ≥ 0.4 かつ p < 0.05（多重比較はHolm補正）
- **非**: 全候補が |ρ| < 0.2 かつ有意でない
- **判定不能**: 上記の中間、または項目数・観測数が不足

**分岐（事前に決定）**:
- **是の場合** → H11「その指標を最大化する生成（棄却サンプリング）は、記憶可能性を実際に向上させるか」へ進む。
  ここで初めて棄却サンプリングを実装する（検証済みの指標を最適化するため）。
- **非の場合** → H11'「記憶可能性は集団内の位置ではなく、**個体内の不調和**（杉森原則6：あえて入れた不釣り合いな要素）で決まる」へ。
  この場合は指標ではなく生成side の介入（不調和要素の注入）を操作変数にした実験へ移る。
- **判定不能の場合** → 参加者・項目を増やして問い直す。**新しい問いに逃げない。**

## 9. 教訓（この研究プロセス自体から）

- **ランダム化した2群をそのまま比べない。** 交絡変数（ここではレア度）が結果変数（形の複雑さ）を直接決めている場合、群間の構成差がそのまま"効果"に化ける。**1軸だけ振るsweep設計**を最初から使うべきだった。
- **単一指標で結論を出さない。** 独立した第二の指標が、実験計画の欠陥を暴いた。
- **否定結果は記録して残す。** プレプリントは永久に残るため、後から矛盾が出る方が損害が大きい。

### 2026-07-19 — 【A2】記憶可能性の指標探索（判定不能）

### 2026-07-19 — 【A1・B2】機械シルエットクイズで(a)の残差を初めて定量化（是）
- **問い**: 生成キャラは人手設計より識別しにくいか。人を集めずに測れるか。
- **実験**: シルエット→カラー検索。参照1025体 vs 生成80体。
- **判定**: **是**。ギャラリーを80体に揃えた top-1 で **参照0.818 vs 生成0.575（−0.243）**。k択の差は k=2:−0.023 → k=32:−0.187 と**単調に拡大**。8択の個体別正解率 p=5e−5。
- **決定**: 「少数では見分くが多数では埋もれる」= 集合の性質の問題（B2を支持）。生成のSDは参照の1.8倍 → **底上げでなく「埋もれた個体を弾く」設計**が正しい打ち手。
- **人間データ(n=1)**: 3択一致率0.542 p=0.028（A3暫定是）。記憶テストは生成が上（n.s.）で機械と逆向き → 仮説「**覚えやすいが見分けにくい**」。

### 2026-07-19 — 【指標バグ】穴埋め補正がH6の判定を反転させていた
- **問い**: common14体で輪郭6.26などの異常値が出るのはなぜか。

### 2026-07-18 — 【B1】公式ロスター1025体の統計解析（是）
- **問い**: 人手設計は"格"を何で符号化しているか。
- **実験**: 1025体の指標測定 + Kruskal-Wallis / Jonckheere / Mann-Whitney / TOST / χ² / 相関 / 判別 / クラスタ妥当性。
- **判定**: **是**。輪郭 通常2.00→伝説2.60（**δ=−0.487 大**、Holm p=4e−12）。**色数は等価性検定を通過**（TOST p=0.003）＝差がないと積極的に言える。
- **崩れた主張**: 進化段階では複雑にならない（KW p=0.22）／14体型は5指標で分離しない（CV23.7% vs 基準21.1%）／伝説と幻に差なし（格は3段でなく2段）／**エッジ密度も格で増える**（ε²=0.070 最大）→「色でなく形」は「**色数でなく形と内部密度**」へ要修正。
- **副産物**: 必要n算出 → Δ=0.20の検出には1条件42体。

### 2026-07-18 — 【C1】フォルムファーストの効果（判定不能）

### 2026-07-18 — 【C1・H5】課題①（レア度が骨格を上書きする）を発見・修正（是）
- **問い**: 高レアだと蛇も虫も鳥も「翼＋棘の塊」になるのはなぜか。
- **判定**: **是（失敗モードとして確認）**。レア度指示に「翼・角・棘を足す」を含めていたため、**より具体的な指示が抽象的な骨格指定に勝っていた**。3回の独立実行で再現。
