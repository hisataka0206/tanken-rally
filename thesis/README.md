## 0. 研究の進め方（このプロジェクトの規律）★最初に読むこと

本プロジェクトは**仮説駆動**で進める。思いつきで施策を実装しない。

```
研究主題（AIで素晴らしいキャラを生み出し続ける）
  ↓
① 主題を支える【仮説】を1つ立てる
  ↓
② その仮説を検証する【実験計画】を立てる
   ・測定する量、判定基準、必要サンプル数を【事前に】決める
   ・是のとき／非のとき、それぞれ次に何を問うかも【事前に】決めておく
  ↓
③ 実験を実施し【是 / 非 / 判定不能】を判定する
  ↓
④ 結果を踏まえて【次の仮説】を立てる
   ・是 → その成立を前提に、一段深い問いへ
   ・非 → 否定された内容を踏まえ、別の説明を問う
   ・判定不能 → 検出力・交絡を直して問い直す（新しい問いに逃げない）
  ↓
①へ戻る（主題に到達するまで反復）
```

### 守る規則

1. **事前登録**: 判定基準・必要nは実験の前に書く。結果を見てから基準を決めない。
2. **分岐の事前設計**: 是／非の両方について、次の仮説を先に書く。後付けの正当化を防ぐ。
3. **判定不能を是と呼ばない**: 検出力不足は「効果なし」でも「効果あり」でもない。
4. **未検証の代理指標を最適化しない**: 代理を使うなら、先にその妥当性を検証する。
5. **否定結果を残す**: 反証された仮説は消さず、判定と根拠を記録する（§1の表）。
6. **交絡を先に潰す**: ランダム化した2群をそのまま比べない。1軸だけ振る。

### 提案・議論のトーン

施策の提案は必ず「**どの仮説を検証するためか**」から始める。
「次は◯◯を実装しましょう」ではなく「**仮説Hnを検証するには実験Eが必要で、その手段が◯◯**」の形にする。

## 4. なぜ「投稿不可」なのか（S4が崩れた経緯）

詳細は `analysis/embedding-validation-memo.md`。要約:

1. 当初 E-A で「介入後は平均輪郭 2.21 vs 介入前 1.75（**差+0.46**）、σも 0.50 vs 0.39」→ 識別性が上がったと解釈した。
2. 独立指標（DINOv2埋め込みのペアワイズ距離）で検証 → **差が出ない。むしろ符号が逆**（0.331 vs 0.351、p=0.29）。
3. 原因を調査 → **2条件のレア度構成が揃っていなかった**（post は epic/legend が10/12体、pre は5/12体）。レア度自体が輪郭を強く決めている（common 1.34 → legend 2.36）。
4. **同一レア度どうしで比較し直すと**、形状指標の差は **+0.46 → +0.14**（約7割が交絡）、埋め込みは **−0.006（p=0.80）**。
5. → **2指標の不一致ではなく、実験計画の不備**。両指標とも統制後は「ほぼゼロ」に収束する。

**効果がゼロと確定したわけでもない**（epic +0.20 / legend +0.23 と符号は揃う）。現データでは**判定不能**が正確。

## 5. 現在の仮説と実験計画（事前登録）

### 検証中: H10「記憶可能性は孤立効果で説明できる」

**なぜこの仮説か**: H9 が非（現行の形状指標では記憶可能性を説明できない）だったため、別の説明が要る。
理論的根拠は記憶研究の**孤立効果 / von Restorff effect**（集団の中で異質なものほど記憶に残る）。
これは杉森建の原則7（あえて崩して記憶に残す）とも整合し、**記憶可能性は個体の属性ではなく集団に対する相対的位置で決まる**という予測を生む。

**測定する量**: 項目ごとのヒット率（再認課題で「見た」と答えられた割合）
**予測変数**: 重心距離 / 近傍孤立度 / 最近傍距離 / マハラノビス（すべて参照ロスター1025体を母集団として計算）

**実験計画**:
- 固定項目セット（study 45・lure 45）を全参加者に提示 → **分析単位は参加者ではなく項目**
- source（生成/参照）を study と lure で厳密に均衡（各 生成25＋参照20）
- 候補指標の値が広く散るよう層化抽出（予測変数の分散を最大化＝検出力を最大化）
- 提示 1.2 秒 → 20 秒の干渉課題 → 再認 90 試行
- 参加者 5 名 → **項目あたり5観測 × 45項目**

**判定基準（事前に決定）**:
- **是**: いずれかの候補指標が、項目ヒット率と ρ ≥ 0.4 かつ p < 0.05（多重比較はHolm補正）
- **非**: 全候補が |ρ| < 0.2 かつ有意でない
- **判定不能**: 上記の中間、または項目数・観測数が不足

**分岐（事前に決定）**:
- **是の場合** → H11「その指標を最大化する生成（棄却サンプリング）は、記憶可能性を実際に向上させるか」へ進む。
  ここで初めて棄却サンプリングを実装する（検証済みの指標を最適化するため）。
- **非の場合** → H11'「記憶可能性は集団内の位置ではなく、**個体内の不調和**（杉森原則6：あえて入れた不釣り合いな要素）で決まる」へ。
  この場合は指標ではなく生成side の介入（不調和要素の注入）を操作変数にした実験へ移る。
- **判定不能の場合** → 参加者・項目を増やして問い直す。**新しい問いに逃げない。**

### 保留中: H3'「フォルムファーストは識別性を上げる」の再実験
必要n = **1条件42体**（効果Δ=0.20・検出力80%で算出済み）。レア度を固定し、両条件とも①修正後プロンプトで揃えること。

## 9. 教訓（この研究プロセス自体から）

- **ランダム化した2群をそのまま比べない。** 交絡変数（ここではレア度）が結果変数（形の複雑さ）を直接決めている場合、群間の構成差がそのまま"効果"に化ける。**1軸だけ振るsweep設計**を最初から使うべきだった。
- **単一指標で結論を出さない。** 独立した第二の指標が、実験計画の欠陥を暴いた。
- **否定結果は記録して残す。** プレプリントは永久に残るため、後から矛盾が出る方が損害が大きい。
