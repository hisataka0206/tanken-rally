# [[CM動画]] ストーリーライン案（15〜30秒）

> 作成日: 2026-07-08 / 更新: 2026-07-08（A案を[[親視点]]で詳細化） / [[たんけんラリー]] のプロモーション動画用
> キャラ素材（[[キャラクターストーリー]]・guide各ポーズ）とアプリ実画面を活用する前提

## 共通メッセージ

**「いつもの駅が、ぼうけんになる。」**
訴求の核: ①準備いらずの手軽さ（駅名だけ） ②歩く×集める×残すの3つの楽しさ ③思い出が「たんけんノート」として形に残る

## A案「たいくつな休日が、たんけんになる」（30秒・本命）

ターゲット: 保護者（小学生の親）。トーン: 温かい・エモ系。実写（親子・[[フリー素材]]で代替可）＋アプリ画面＋キャラアニメの構成。

### 演出原則（[[親視点]]）

1. **カメラは常に親の位置**: 前半は親の顔を見せない。POV（親の目線）と肩ナメ（親の肩越しに子を見る）だけで進め、C6で初めて親の笑顔を見せて感情を解放する。
2. **物語の主語は親**: 「子どもが遊ぶ話」ではなく「親が"ひま"を解決し、一日の手応えを得る話」。冒頭と結びに親のモノローグを置く。
3. **訴求は3段テロップ＋差別化1本**: 行動価値「あるく→つかまえる→のこす」を骨格に、差別化「無料・アプリ不要」は前半（C2）と最後（C8）の2回出す。1回では記憶に残らない。

### 訴求設計メモ

- **3つの記憶ポイント**: 「駅名ひとつ」（手軽さ）／「あるく・つかまえる・のこす」（体験価値）／「無料・アプリ不要」（差別化）。この3点以外のテロップは足さない。
- **親モノローグの対構造**: C1「日曜のたびに、聞くセリフ。」→ C7「"ひま"が、こんな一日になるなんて。」で親の変化を完結させる。
- **実写はフリー素材で成立する構図**: POV・肩ナメ・後ろ姿・影・手元中心にしたので、顔が必要なのはC6の親の笑顔1カットのみ。素材調達のハードルが低い。
- **画面はめ込み**: C2・C5のスマホ画面はbeta環境の画面録画を合成。実物のUIを見せることが信頼につながる。

## A-2案「コンビニで刷って、出発。」（30秒・説明寄せVer）

ターゲット: 保護者。トーン: A案の温かさを残しつつ「使い方が具体的にわかる」説明型。A案と同じ素材（親視点実写＋画面録画＋キャラPNG）を流用し、**[[PDF印刷]]〜[[コンビニ印刷]]の実際の流れ**を見せることで「家にプリンタがなくても大丈夫」を伝える。

### 前提（印刷フロー）

- 地図PDF・[[たんけんノート]]PDFは、家庭用プリンタではなく**コンビニの印刷アプリ経由でマルチコピー機から印刷する想定**（例: セブン‐イレブン netprint、ファミマ／ローソン PrintSmash 等）
- CM内では特定チェーン名・アプリ名は出さず「コンビニで印刷」と汎用表現にする（タイアップ時のみ実名）

### カット表

|---|---|---|---|---|---|
| C1 | 0-3 | 親の手元スマホPOV: 駅名を選ぶ→地図とスポットがポンポン出現。ZOOMYがバトンを掲げる（loupe_g1） | ポンッ（SE）＋軽快なBGM／ナレ「使い方は、かんたん。」 | 「① 駅名をえらぶ」 | 説明型宣言。冒頭からステップ番号で見せる |

### ポイント

- **A案との使い分け**: A案=情緒で「やってみたい」を作る認知用、A-2案=手順で「自分にもできる」を作る理解用。Web/LPやセミナー、店頭サイネージなど説明が許容される面に向く。
- **コンビニ印刷は2回見せる**: 往路の地図（C3）と復路のノート（C6）。「印刷のために家に帰る」という違和感を消し、外出動線の中で完結することを示す。
- **差別化テロップが3点に増える**: 「無料・アプリ不要」に「プリンタ不要」を追加。保護者の"やらない理由"を3つ同時につぶす。
- **素材流用**: C1・C5はA案と共通素材。新規に必要なのはコンビニ店内（マルチコピー機）の実写のみで、フリー素材が乏しい場合は自前で1カット撮影すれば足りる。

## B案「キャラたちがさそう」（15秒・子ども直撃/SNS縦型向け）

ターゲット: 子ども本人（YouTube Kids・TikTok等の縦型）。トーン: ハイテンポ・キャラ主導。全編アニメ＋画面録画で実写不要＝制作が軽い。

| 秒 | 映像 | 音・セリフ |
|---|---|---|
| 0-2 | 黒画面からZOOMYがレンズでこちらを覗き込む（どアップ） | ZOOMY「きみの街、調査ちゅう！」 |
| 2-5 | 地図がバッと開き、ルートが線で引かれる（画面3の録画＋キャラ乗せ） | テンポの良いBGM、SE連打 |
| 5-9 | AR捕獲の連続カット: TAFFY出現→パシャ→ゲット、NUTTY出現→パシャ→ゲット（実画面） | 「ゲット！」×2 |
| 9-12 | 図鑑画面がスクロールし、シルエットが次々カラーに変わる | コンプ音（ピロリン） |
| 12-15 | 3キャラがスコア紙吹雪の中でジャンプ→ロゴ | 全員「たんけんラリー！」 |

ポイント: 「？？？のシルエットが埋まっていく」collection欲を最強のフックにする。15秒で完結、30秒版はA案と併用。

## C案「この1000点、なんの点数？」（20秒・謎かけ型）

ターゲット: 保護者＋教育関係者。トーン: 知的・ストーリー逆算型。

| 秒 | 映像 | 音・セリフ |
|---|---|---|
| 0-3 | スコア画面「1024点」のどアップ。NUTTYが数字の上でドヤ顔 | ナレ「この1024点、テストの点数じゃありません」 |
| 3-12 | 巻き戻し演出（逆再生風）: ノート完成←写真撮影←キャラ捕獲←路地の探検←駅の改札、と1日を遡る | 逆回転SE→各シーンで正転に切替 |
| 12-17 | 冒頭の駅名入力画面に到着。「はじまりは、駅名ひとつ」 | BGM転調（前向き） |
| 17-20 | ロゴ＋「歩いた分だけ、点になる。」＋QR | ナレ「たんけんラリー」 |

ポイント: 「スコア＝歩いて発見した量」というアプリ独自の価値を一点突破で伝える。夏休みの自由研究シーズンに親和性が高い。

## おすすめ

**本命はA案（30秒）＋B案（15秒カットダウン）の2本立て**。Aで保護者に価値を伝え、Bで子どもに「キャラを集めたい」を植え付ける。**A-2案（説明寄せVer）はLP・セミナー・説明が許される面での併用枠**として、A案と素材を共有しながら制作する。同じ素材（アプリ録画＋キャラPNG）を使い回せるので制作効率も良い。

## 制作メモ

- 素材: キャラは切り出し済み透過PNG（ポーズ豊富）。アプリ画面はbeta環境の画面録画で撮れる
- 実写パート（A案）は親子フリー素材でも代替可。ナレーションはAI音声で仮組みできる
- 音楽: 子ども向けの明るいポップ（フリーBGM）。SEは「ポンッ」「キラン」「ピロリン」を多用
- 尺展開: A案30秒 → 15秒カットダウン（0-3秒カット＋モンタージュ短縮）も作れる構成にしてある
