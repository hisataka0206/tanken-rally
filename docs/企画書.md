# たんけんラリー（仮称）
## ゲーム企画書 v0.1
> 作成日: 2026-04-26

---

## 1. ゲームコンセプト

**「駅を起点に、街を探検して、レポートを書く。世界と競う。」**

プレーヤーは駅名を入力するだけで、周辺の史跡・スイーツショップ・地名の由来スポットを発見し、実際に足を運び、写真を撮り、探検レポートを仕上げる。

スタンプラリーの「行って確認する」体験に、**地元の知識・発見・創作・競争**を組み合わせた、小学3年生〜高校生が楽しめる街歩き × 学習 × SNS型ゲーム。

## 2. ターゲットユーザー

| 層 | 年齢 | 利用シーン |
|---|---|---|
| **メイン** | 小学3年生〜中学生（8〜15歳） | 休日の外出、家族お出かけ、友人との遊び |

| **保護者同伴** | 親世代（30〜45歳） | 子どもと一緒に探検 |

## 3. ゲームの流れ（プレーヤー視点）

```
STEP 1: 駅名を入力
  └─ 例）「高円寺」「鎌倉」「浅草」など

STEP 2: スポット一覧を受け取る
  ├─ 史跡・文化財（必須訪問スポット）
  ├─ スイーツ・お菓子屋さん
  └─ 地名の由来スポット（なぜこの名前？のストーリー付き）

STEP 3: 行きたい場所を選ぶ
  └─ 史跡は最低1件必須。その他は自由選択

STEP 4: 探検マップをもらう（PDF）
  ├─ 選択したスポットを最短ルートで結んだ地図
  ├─ 各スポットの簡単な説明と見どころ
  └─ 印刷 or スマホで持ち歩き

STEP 5: 現地を巡る
  ├─ 各スポットで写真を撮る
  └─ 写真はシステムに自動保存（タイムスタンプ・位置情報付き）

STEP 6: 気に入った写真を選ぶ
  └─ 探検レポートに使う写真をセレクト

STEP 7: 探検レポートを完成させる
  ├─ システムが「写真 + 時刻 + 移動データ」でレポート骨格を自動生成
  └─ プレーヤーが説明文・コメントを書き加えて完成

STEP 8: スコアが出る
  └─ 世界ランキングに登録・公開
```

## 4. スポット検索の設計方針

### 4-1. 検索カテゴリ

| カテゴリ | 内容 | 必須/任意 |
|---|---|---|
| 史跡・文化財 | 城跡・神社仏閣・碑・旧跡 | **必須**（最低1件） |
| 地名由来スポット | 地名の語源にまつわる場所・看板・景色 | 推奨 |
| スイーツ・菓子店 | ケーキ屋・和菓子屋・せんべい屋など路面店 | 任意 |
| 自然・公園 | 池・川・丘・公園 | 任意 |

### 4-2. スポット情報として表示するもの
- スポット名・住所・地図上の位置
- 見どころの説明（小学生〜高校生向けの言葉で）
- 地名由来の場合：「なぜこの名前なのか」のストーリー
- 営業時間・入場料（該当する場合）

## 5. 探検マップ（PDF）の仕様

- 選択したスポットを最短ルートで結んだ地図（徒歩ルート）
- 各スポット番号と名称・簡易説明を地図に配置
- 総距離・推定所要時間を記載
- A4縦または横で印刷しやすいレイアウト
- QRコード付き（スマホで開くとGoogleマップなどへリンク）

---

## 6. 探検レポートの仕様

### システムが自動生成するもの
- 訪問スポットの一覧（訪問時刻付き）
- 移動距離・所要時間のサマリー
- 選択した写真の配置（時系列）
- 各写真の撮影時刻・場所名

### プレーヤーが書き加えるもの
- 各写真・スポットへのコメント・感想
- タイトル・締めくくりの一言

### 完成レポートのフォーマット
- PDF形式で出力・保存・シェア可能
- 表紙に日付・探検した街・プレーヤー名を表示

## 7. スコアリング設計

| 評価軸 | 内容 | 配点（仮） |
|---|---|---|
| **訪問完了率** | 選択した全スポットを訪問したか | 〜30点 |
| **移動距離** | 実際に歩いた距離（ボーナス要素） | 〜10点 |
| **写真の枚数** | 撮影した写真の量 | 〜10点 |
| **写真の質** | AI評価（構図・明るさ・スポットとの一致度） | 〜20点 |
| **レポートの質** | 文字数・コメントの充実度・オリジナリティ（AI評価） | 〜30点 |
| **合計** | | **最大100点** |

スコアはプレーヤー名と共に公開ランキングに登録。同一駅の探検者同士で比較できる。

## 8. ランキング設計

- **週間ランキング**：直近1週間の新規探検スコア
- プレーヤー名は任意のニックネーム（実名不要）

## 10. マネタイズ案（将来検討）

### 10-1. 全体の方向性（複数の収益源）

| 案 | 内容 |
|---|---|
| [[フリーミアム]] | 基本無料。レポートのPDFフォーマットや特別デザインは有料 |
| 地域パートナー | スイーツ店などがスポットに掲載料を支払う（口コミ型広告） |
| 学校・教育機関向け | 校外学習・総合学習の教材として法人販売 |
| [[自治体連携]] | 観光振興として自治体が資金提供 |
| [[キャラグッズ化提携]] | 生まれたAIキャラをグッズ化サービスと提携し、送客の[[紹介料]]を得る（→ 10-2 の具体案） |

### 10-2. キャラ[[グッズ化]]提携（[[紹介料]]モデル）【具体案】

> 構想メモ（元資料 `monetization-concept-character-goods.md` より転記・調査補正）。数字は目安で、実際は先方と交渉して決める前提。

**やりたいこと**：たんけんラリーで生まれたAIキャラ（[[ゴキキツ]]等）を、外部の[[グッズ化]]サービスと[[提携]]して商品化。自サイト経由で発注が入ったら売上の一部を**紹介料（[[アフィリエイト]]／レフェラル）**として受け取る。在庫リスクなしで、キャラの"所有欲・愛着"を収益に変える導線。ValueProposition の「最初の発見者」「世界にひとつ」の所有感とも噛み合う。

#### 提携先候補（2026-07 時点・Web調査済み）

| | [[tukutte]]（ツクッテ） | [[Charaxy]]（キャラクシー） |
|---|---|---|
| 運営 | [[イメージ・マジック]] | [[ソコラボ]] |
| 概要 | 写真→AIが最短1分でシールデザイン→その場で発注（2026/7/7 提供開始） | らくがき/写真→AIでオリキャラ生成→グッズ化（旧「らくがきキャラメイカー」をリニューアル） |
| 商品 | シール4種（シルエット／DIYシート／ホログラム／立体フォト） | CM＝キャラ生成、FN＝Tシャツ・アクキー等を最短3日発送。特許「ぷにもちシール」 |
| 強み | 印刷が本業の規模（2025/12期 売上見込 約87.7億円）＝**製造・配送の安定感** | 「オリキャラ→グッズ化」がコンセプトで**商品バリエが広い**。南青山に体験店舗「[[キャラクシーファクトリー]]」（2026/7/1 開店・コンセプト＝"無限のキャラが生まれる場所"） |
| 弱み・論点 | 商品がシール中心・写真ベースの色が濃い | 入稿画像をAIが"いい感じに"加工し**元絵が変わる**懸念（キャラ一貫性リスク） |

**どちらと組むか**：世界観・グッズ展開の幅なら[[Charaxy]]、オペレーションの堅さ・シール量産なら[[tukutte]]。まず両社に率と権利条件を聞き、良い方を選ぶのが安全。
※[[Charaxy]]運営のソコラボは**グロービス経営大学院が出資**（G-CHALLENGE 2024 大賞）。中の人が知人＝相談しやすい反面、関係性ゆえ**条件は必ず明文化**する。

**キャラ一貫性リスク（重要）**：図鑑の絵とグッズの絵がAI加工でズレると「本物と違う」を招く（子ども向け＝保護者の目も厳しい）。→ **「加工なしで入稿画像そのまま出力するモード」の有無**を両社に確認するのが分かれ目。

#### 提携・課金モデルの選択肢

- **A. [[紹介料]]（レフェラル）型**：送客→先方で発注→成約額の◯%。実装が軽く在庫リスクなし。**まずはこれが現実的**。
- **B. レベニューシェア型**：共同商品で売上分配。率は高く取りやすいが調整が重い。
- **C. 卸・マージン型**：自社が窓口となり製造委託して差額を取る。利益は大きいが決済・CS・販売者責任を負う。

#### 紹介料はいくらが妥当か（調査で補正）

- **全体相場**：アフィリエイト成果報酬率は**10〜30%**の広いレンジ。ただし**原価が乗る物販ほど低い**。
- **物販の実勢（今回のWeb調査）**：物販は「商品単価の数%」が多く、**アパレルEC ≒ 売上の5%前後／食品EC ≒ 10%前後**（有力メディアは特別報酬で12%以上も）。**[[POD]]（受注生産）は製造原価・送料で粗利が薄く、目安3〜8%の低めに寄りやすい**。
- **落としどころ**：着地は**成約額の8〜10%**を狙い、提示は**15〜20%**（＝ただの送客でなく「キャラという素材＋ファン導線」を提供する価値を主張して上を狙う）。
- **下限**：相場下限（5〜8%）と、後述の**自社コスト逆算**の**高い方**を採用。
- **基準額に注意**：「売上総額に対して◯%」で握れるとこちら有利（製造原価控除後だと実額が下がる）。
  ※元メモの"着地10%"は物販アフィリでは強気寄り。粗利の薄いPODでは**8%前後が現実的な着地**の可能性。

#### 自社コストからの下限（※自分で数字を埋める）

相場だけで決めず「これ以下なら割に合わない」下限を出す：①キャラ生成コスト（[[生成AI]]利用料・作り直し・自分の時間）＋サイト運営（ホスティング・保守・導線実装）＋発注1件あたりの対応 を洗い出し → ②固定費／変動費に分け → ③想定成約数で割って**発注1件あたりの回収必要額** → ④平均客単価で割って**必要最低料率(%)** に換算。相場下限とこの逆算値の**高い方**を実下限に。

#### リスク：グッズ品質クレームは自社に来るか

- **法的責任**：純粋な紹介（送客）型で、契約・購入するのが先方（＝販売者は tukutte／Charaxy）なら、商品欠陥の責任は基本**先方**。卸・マージン型で自社が窓口になると販売者責任を被る。→「誰が販売者か」を契約と表示で明確化（※これは法的助言ではないので、契約前に専門家へ確認）。
- **評判・体感クレーム**：法的責任とは別に飛んできやすい。ユーザーは「このサイトのキャラで作ったグッズ」と認識するため、品質不満はこちらに向く。→ 送客時に「販売・製造は◯◯社」と明示／免責明記／品質基準・返品・CSを先方担当に／**組む前に自分で実物を発注して品質確認**。

#### [[Charaxy]]（知人）への進め方

「クレーム」ではなく「一緒に良くしたい相談」として持っていく。フレーミング＝**協業の相談＋機能の質問**（「このキャラを軸にそちらへ送客したい。見た目を揃えたいので入稿画像そのまま出せるモードある？」）／共通利益を前に（一貫性が保てる＝ファンが安心して買う＝先方の売上も伸びる）／逃げ道を残す（無ければ要望として）／ただし**料率・入稿仕様は言葉に残す**。

#### 詰めておきたい論点

著作権・利用許諾（AI生成キャラのグッズ化・販売・二次利用範囲。特に Charaxy の権利まわりの但し書き）／計測方法（専用リンク・クーポンコード・UTM 等）／支払い条件（最低支払額・締め支払いサイト・返品時の扱い）／子ども向けとして課金・外部送客が保護者の不安にならないUI設計。

#### 次のアクション

1. tukutte／Charaxy に[[アフィリエイト]]・[[提携]]プログラムの有無を問い合わせる（**Web上に公開プログラムは確認できず＝個別提案が前提**）。
2. 送客見込み（月間ユーザー数・想定成約率）を試算し、交渉材料にする。
3. 率レンジ（提示15〜20%／着地8〜10%）で打診。**加工なし入稿モードの有無を必ず確認**。

#### 調査メモ（2026-07-17・Web確認）

- **tukutte**：[[イメージ・マジック]]が 2026/7/7 提供開始。AIシール、商品4種。運営元は印刷本業の規模企業（2025/12期 売上見込 約87.7億円）。

## 11. 類似サービスとの差別化

| サービス | 類似点 | HaaS との違い |
|---|---|---|
| スタンプラリー | 場所を巡る体験 | デジタル完結・自由なルート設計・レポート作成 |
| Googleマップ | 場所検索・ルート案内 | 子ども向け編集・ゲーム性・スコアリング |
| しまじろう的教育コンテンツ | 子ども向け学習 | 外出・体験が必須・実際の街と連動 |
| 写真SNS（Instagram等） | 写真投稿・シェア | 目的地設定・レポート作成・スコア競争 |
