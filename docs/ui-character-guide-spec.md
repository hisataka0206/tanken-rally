# [[UIキャラクター案内役]] 配置設計書

> 作成日: 2026-07-08 / [[キャラクターストーリー]]（docs/characters-story.md）の3キャラを各画面の案内役として配置する設計
> ステータス: 受け皿実装済み（v=100）。`src/assets/characters/guide/` に素材PNGを置くだけでガイドが出現する。
> 画面4はスポットカテゴリ連動（既存アセット流用）で**動作中**。

## 1. 方針

- 案内役は **ZOOMY（ズーミー/虫眼鏡・内部ID loupe）／TAFFY（タフィー/キャンディ・taffy）／NUTTY（ナッティ/どんぐり・oakchap）** の3体。
- 役割分担: ZOOMY＝進行役（次にやることを示す）、TAFFY＝盛り上げ役、NUTTY＝コミックリリーフ（画面の隅で和ませる）。
- **操作の邪魔をしない**: すべて `pointer-events: none` の装飾レイヤーに置き、ボタン・入力欄には重ねない。
- **主役1体＋脇役**: 各画面で大きく出すのは1体（メインガイド）、他はカードの縁や隅に小さく。3体を同格に並べない。
- **画像が無い間も壊れない**: `onerror` で自動非表示にする実装とし、PNGをフォルダに置いた時点で自然に出現する。

## 2. 素材仕様（作成依頼用）

- 形式: 透過PNG、長辺 512px 目安（UI装飾用なので軽量に。1枚 100KB 以下推奨）
- 配置先: `src/assets/characters/guide/`
- 命名: `<内部ID>_g<画面番号>.png`（例: `loupe_g1.png`, `taffy_g3.png`, `oakchap_g7.png`）
- 画面4（写真撮影）は **既存アセットを流用**するため新規作成不要: `loupe_get.png` / `taffy_get.png` / `oakchap_discovery.png`
- 向きの指定: メインガイドは「画面の中央側を向く」構図にする（左配置なら右向き）

## 4. 実装方式（素材が届いたら着手）

- 新規モジュール `src/utils/guides.js`: 画面番号→ {charId, ファイル名, 配置クラス} のマニフェストと `mountGuides(stepId)` を提供。
- 各 step セクションに `<div class="guide-layer">` を追加し、`showStep()` から `mountGuides()` を呼ぶ。
- `.guide-char` 共通CSS: `position:absolute; pointer-events:none; z-index:2;` ＋配置クラス（`.guide-tl/.guide-tr/.guide-bl/.guide-br/.guide-beside-title` 等）。
- 画像 `onerror` → 該当要素を `display:none`（素材未着でもレイアウト不変）。
- アニメは `prefers-reduced-motion: reduce` で無効化。
- モバイル（≤768px）はメインガイドのみ表示し脇役は非表示、が既定（画面が狭いため）。
