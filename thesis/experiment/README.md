# [[シルエットクイズ]] — C1の測定装置

上位文書: `../research-thesis.md`（C4）／ `../ai-vs-creator-gap.md`（§4-B 残差測定）

**なぜ最初にこれを作るのか**: 我々は代理指標に二度裏切られている（σ(輪郭)＝レア度の交絡、埋め込み＝効果ゼロ）。
未検証の代理指標を最適化する施策（棄却サンプリング等）を先に入れると、**効いたか判定できない**まま S4 と同じ「判定不能」に戻る。
よって**先にメジャーを作る**。本装置は測定器であり、同時にアプリ機能の原型でもある。

---

## 何を測るか

| 課題 | 内容 | 何のため |
|---|---|---|
| **A: 3択（奇数選び）** | 3つのシルエットから「いちばん形が違う」を選ぶ | **代理指標の妥当性検証**。人間の判断と計算距離が一致するか |
| **B: 記憶テスト** | 提示 → 20秒の干渉課題 → 再認（見た/見てない） | **記憶可能性の直接測定**（[[杉森建]]の目的関数）。初回接触で測るため既知性の交絡を受けにくい |

課題Bは **d'（判別力）** も算出する（ヒット率と誤警報率から）。単なる正答率より、当てずっぽうの影響を受けにくい。

## 使い方

```bash
# 1) 刺激を生成（初回のみ。参照画像は著作物由来のためコミットされない）
cd thesis/experiment
python3 make_stimuli.py --ref-n 40 --min-dex 650

# 2) ローカルサーバを立てて開く（fetch を使うため file:// では動かない）
cd ../..            # リポジトリ直下へ
python3 -m http.server 8080
#   → http://localhost:8080/thesis/experiment/silhouette-quiz.html

# 3) 実施 → 「結果をダウンロード」で quiz_*.json を保存
#    集めた json を thesis/experiment/results/ に置く

# 4) 分析
python3 thesis/experiment/analyze_quiz.py 'thesis/experiment/results/*.json'
```

## 設計上の注意（交絡の回避）

- **既知性の交絡**: 参照は既定で `dex >= 650`（後期世代）から抽出し、有名個体を避けている。参加者には「ポケモンにどれくらい詳しいか」を必ず聞き、分析時に層別すること。
- **画風の手がかり**: 3択は**同一 source 内**（生成同士／参照同士）でのみ出題する。混在させると画風差が手がかりになり、形の判断を測れない。
- **位置・大きさの手がかり**: 刺激は bbox 正規化・中央配置済み。**形のみ**が手がかりになる。
- **順序効果**: 課題A→Bの順。Aで見た個体がBの記銘に影響しうるため、厳密には別参加者で回すのが望ましい（`mode` で片方だけ実施可能）。

## 判定基準（事前に決めておく）

- **Q1**: 3択の一致率が偶然（1/3）を有意に超えるか。
  - 超える → 形状指標は知覚を部分的に予測する。以後、指標での代用に根拠ができる。
  - **超えない → これまで指標で導いた結論は再解釈が必要**。棄却サンプリングの最適化対象としても不適切なので、指標の作り直しが先。
- **Q2**: 生成 vs 参照で記憶ヒット率・d' に差があるか。差の向き（生成が低い）とその大きさが、**(a)の残差の最初の定量値**になる。

## 必要な参加者数（目安）

- Q1（一致率が1/3を超えるか）: 1人あたり24試行なら、**5〜10人**で十分な検出力が得られる見込み。
- Q2（生成 vs 参照の差）: 個体別ヒット率まで見るなら **20〜30人**は欲しい。まず身近な数名で装置の動作確認をしてから広げるのが安全。

## ファイル

- `make_stimuli.py` — 刺激生成（外輪郭ベタ塗り・正規化）。生成キャラには `results.json` と `canonical_metrics.json` からメタと指標を結合する。
- `silhouette-quiz.html` — 測定装置本体（依存なし・オフライン動作）。
- `analyze_quiz.py` — Q1/Q2 の分析（二項検定・並べ替え検定・個体別相関）。
- `stimuli/` — 生成される刺激。**コミットしない**（`.gitignore` 済み。参照は著作物由来のため）。
- `results/` — 収集した回答 json を置く場所。

## [[IP]]の扱い

参照ロスター由来のシルエットは**ローカル実験のためだけ**に生成し、再配布しない。公開するのは導出統計のみ。
`make_stimuli.py` を配布すれば、画像を配らずに第三者が同じ刺激を再現できる。
