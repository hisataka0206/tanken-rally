## 4. なぜ「投稿不可」なのか（S4が崩れた経緯）

詳細は `analysis/embedding-validation-memo.md`。要約:

1. 当初 E-A で「介入後は平均輪郭 2.21 vs 介入前 1.75（**差+0.46**）、σも 0.50 vs 0.39」→ 識別性が上がったと解釈した。
2. 独立指標（DINOv2埋め込みのペアワイズ距離）で検証 → **差が出ない。むしろ符号が逆**（0.331 vs 0.351、p=0.29）。
3. 原因を調査 → **2条件のレア度構成が揃っていなかった**（post は epic/legend が10/12体、pre は5/12体）。レア度自体が輪郭を強く決めている（common 1.34 → legend 2.36）。
4. **同一レア度どうしで比較し直すと**、形状指標の差は **+0.46 → +0.14**（約7割が交絡）、埋め込みは **−0.006（p=0.80）**。
5. → **2指標の不一致ではなく、実験計画の不備**。両指標とも統制後は「ほぼゼロ」に収束する。

**効果がゼロと確定したわけでもない**（epic +0.20 / legend +0.23 と符号は揃う）。現データでは**判定不能**が正確。

## 8. 教訓（この研究プロセス自体から）

- **ランダム化した2群をそのまま比べない。** 交絡変数（ここではレア度）が結果変数（形の複雑さ）を直接決めている場合、群間の構成差がそのまま"効果"に化ける。**1軸だけ振るsweep設計**を最初から使うべきだった。
- **単一指標で結論を出さない。** 独立した第二の指標が、実験計画の欠陥を暴いた。
- **否定結果は記録して残す。** プレプリントは永久に残るため、後から矛盾が出る方が損害が大きい。
